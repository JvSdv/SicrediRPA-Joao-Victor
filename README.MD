# Projeto RPA para calcular variação de um valor em um período de tempo, utilizando um índice financeiro.


### configuração de ambiente global

- Para configuração do ambiente de cada projeto, é necessário acessar o diretório do projeto e ler o README.MD do projeto.

- Utilizando Git Flow, comandos para instalação em linux:
```bash
  sudo apt-get update
  sudo apt-get install git-flow
```
- Inicializando o git flow:
```bash
  git flow init
```
